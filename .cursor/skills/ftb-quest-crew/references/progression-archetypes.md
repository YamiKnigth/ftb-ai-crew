# Progression Archetypes (reasoning guide)

Do **not** force every mod into the same ladder. Choose an archetype after researching the mod, then invent a flow that fits that mod's real systems.

## Archetype A — Machine ladder (tech factories)

Typical order:

1. Intro + configurator/wrench mindset  
2. Gate materials (unique ores/alloys/circuits)  
3. First machine that unlocks the rest  
4. Power/logistics enough to run that machine  
5. Core processing loop (1x → better tiers if the mod has them)  
6. Mid machines that depend on earlier products  
7. Upgrades / factories / automation  
8. Optional late utility (teleporters, miners, multiblocks)

Use when the mod is about crafting machines that feed each other.

## Archetype B — Ritual / magic spiral

Typical order:

1. Intro lore + safety tools  
2. Source resource (mana, essence, souls, incense)  
3. First altar/workbench  
4. Basic crafts that prove the loop  
5. Travel/utility spells or familiars  
6. Mid rituals with multi-ingredient setups  
7. Risk/reward end systems

Use when progression is knowledge + ritual setup, not factory throughput.

## Archetype C — Dimension / exploration chain

Typical order:

1. How to enter  
2. Survival kit for the dimension  
3. Key biomes/structures  
4. Boss or landmark goals  
5. Unique loot sinks that matter back in the overworld  

Use when the mod is place-driven.

## Archetype D — Gear / affix tree

Typical order:

1. Base crafting station  
2. Material tiers  
3. Reroll/upgrade systems  
4. Gems/affixes/enchant modules  
5. End-tier sets as optional mastery  

## Archetype E — Storage network

Typical order:

1. Controller/core  
2. Energy or channel rules  
3. Storage cells/drives  
4. Import/export/pattern crafting  
5. Wireless / automation bridges  
6. Late compression or extended crafting

## Design checklist (every mod)

- What is the first “aha” item that makes the mod feel real?  
- What softlocks exist (power, channel, multiblock size, dimension gate)?  
- Which items are variants noise (stairs/slabs) and should be skipped?  
- Where should optional branches fork without blocking the spine?  
- What should each quest teach beyond “obtain item”?  

Output a custom stage list per mod. Stage names may differ from any default list.
