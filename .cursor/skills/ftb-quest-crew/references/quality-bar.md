# Quality Bar (what “good” means here)

A chapter is good when a new player can learn the mod from the quest book alone.

Signals of quality:

1. Correct teaching order for **that** mod’s systems  
2. Quests explain mechanics (GUI, power, logistics, rituals), not only demand crafts  
3. Dependencies match real recipe/world gates  
4. Optional content is visibly optional  
5. EN + ES complete and parallel  
6. No copyrighted quest prose from third-party packs  

Signals of failure:

- Same generic ladder pasted onto every mod  
- “Get X” with no teaching text  
- Softlocks (energy/channels/dimension) ignored  
- Decorative item spam as quests  
- Missing Spanish keys  

The Cursor agent gathers evidence from the server instance and writes files. **Choosing archetype, stage order, quest set, and wording requires reasoning per mod** — that is the crew’s job in-chat, not a one-size-fits-all script.
