# Mekanism — optional enrichment notes

Optional notes if this mod appears in an instance. The crew still researches jars/recipes and reasons a custom flow; this file is only extra context.

## Systems to look for

- Gate materials: osmium, steel, alloys, control circuits  
- Core machines: metallurgic infuser, enrichment, crusher, smelter  
- Power + logistics before scaling factories  
- Ore processing tiers (if present in the installed version)  
- Chemicals / PRC / HDPE midgame  
- Upgrades, teleporter, digital miner as later optional branches  
- Reactors / SPS as a sibling chapter only if those mods/items exist  

## Softlocks to teach

- Wrong cable/pipe/tube mode  
- Infuse buffer stuck on the wrong type  
- Separator dump modes stalling production  
- Building chemical tiers before oxygen/power are stable  

Do not treat this as a rigid template. Verify against the instance version.
