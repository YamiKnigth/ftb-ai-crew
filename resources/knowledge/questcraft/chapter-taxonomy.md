# Chapter Taxonomy (original craft guide)

Use these chapter groups when organizing a quest book. Names are conventions, not requirements.

| Group | Use when |
|---|---|
| Main Questline | Pack-wide goals, onboarding, cross-mod milestones |
| Tech | Machine progression, factories, processing lines |
| Magic | Rituals, mana/essence systems, spellcraft |
| Power | Generators, cables, energy storage, reactors |
| Storage | Controllers, drives, drawers, barrels, wireless access |
| Logistics | Pipes, routers, importers/exporters, sorting |
| Resources | Farming, bees, trees, ores, material multipliers |
| Exploration | Dimensions, bosses, biomes, dungeons |
| Tools and Gear | Weapons, armor, tools, curios, enchanting gear |

Rules:

- One deep mod usually gets one chapter (or a base chapter + advanced sibling).
- Overlapping mods (e.g. power + tech) may place early power in Power and factories in Tech.
- QoL/API mods rarely deserve chapters; mention them in onboarding instead.
